# kafka-wire v0.1.4 — Protocol correctness maintenance

## What changed

- Fetch now reports real leader epochs.
- Unsupported transactional/control batches are rejected without corrupting offsets.
- Version-checked, tested binaries and current multi-platform container tags.

## Install and upgrade

Back up the data directory before upgrading. Transactional producers and read-committed isolation are not supported; this release does not add them.

See [deployment instructions](../../DEPLOYMENT.md) and the attached checksums.

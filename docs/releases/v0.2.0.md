# Kafka Wire v0.2.0

## Added

- An interactive compatibility dashboard with client filters, inspectable settings, measured source provenance, receipt import/export and the actual advertised API ranges.
- Pinned Go/franz-go, Python/kafka-python, Node/KafkaJS and Java/Apache Kafka examples. Each validates five opaque payloads, keys and partition order; Node and Java also validate classic consumer groups and committed offsets.
- An owned-broker runner, CI measurements, a Pages dashboard from the resulting main source, and a downloadable release compatibility bundle with examples and SHA-256 manifests.

## Corrected

Java Admin requires an empty successful CreateTopics configuration list. Produce v9 must omit the newer CurrentLeader tag; protocol constructors now preserve its unknown defaults on success and error paths. Actual wire-handler regression tests cover both findings.

## Verification

All four pinned clients passed the local end-to-end suite. Release CI repeats the checks against the tagged source. Measurements apply to the shown client versions and settings, not every possible client feature.

## Upgrade and limitations

Install the appropriate binary or container from [deployment instructions](../../DEPLOYMENT.md). Persistent storage format is unchanged. Idempotent/transactional producers, replication, exactly-once semantics, the modern consumer group protocol and Kafka Streams remain unsupported. Examples deliberately disable idempotence and compression and use one partition over local PLAINTEXT.

[Deployment and upgrade instructions](https://github.com/csnyder256/kafka-wire/blob/v0.2.0/DEPLOYMENT.md).

Real client checks

The test contract

Create a unique topic, produce five values, then require exact text, JSON, all 256 byte values, an empty payload and Unicode. Verify keys and single-partition offsets. Node and Java additionally join a classic group and verify an explicit offset commit.

python3 scripts/client_check.py --output ./client-checks
python3 -m http.server --directory ./client-checks 8000

Prerequisites: the repository's Go toolchain, Node 22+, Python 3.10+, Java 17+ and Maven. The runner installs pinned Python and Node example dependencies, builds this source, owns a temporary loopback broker and stops it after checking. Choose a new output directory for each run.
